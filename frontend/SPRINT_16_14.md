# Sprint 16.14 — Customer UI System & Single-Language Navigation

Customer-first UI sprint.

- One selected language is enforced across Guest loading, services, emergency/support and navigation.
- Global glass top bar is shared across routed windows.
- Bottom navigation is larger and glassmorphic.
- Welcome banner includes multiple visual effect presets; Admin-facing selection is reserved for the following system-control sprint.
- Recommendations use smaller cards, horizontal smooth scrolling, and a 60-second cadence.
- Messages prioritize Home -> Notification Center -> ZhaoXi Assistant; destructive/action buttons are compact.
- Coupon icon no longer leaks a Chinese glyph in Vietnamese/English.
- Emergency categories open ZhaoXi Assistant with the selected topic; paid 1-to-1 human support is clearly labeled.
- Food restaurant cards are compact.
- Non-food modules no longer use restaurant layout; Housing/Visa/Car Rental/Translation/Travel/Payment/Community/Market route to their correct module browser.
