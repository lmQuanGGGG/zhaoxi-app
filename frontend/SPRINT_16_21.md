# Sprint 16.21 — Customer Search, Discovery & Smart Service Matching

Cumulative release on Sprint 16.20.

- Search now uses the authenticated Customer smart-search API.
- Short/empty queries show personalized discovery instead of an empty search screen.
- Full search ranking combines text relevance with Favorites, Browsing History, Orders and saved city affinity.
- Horizontal module chips filter search without breaking the correct service route.
- Search keeps a small local recent-query list for quick mobile reuse; no private profile data is stored there.
- Every result can show a localized explanation of why it matched.
- ZhaoXi Assistant is a first-class fallback from the Search screen.
- Global top bar and glass bottom navigation remain consistent.
- Single-language remains mandatory.
