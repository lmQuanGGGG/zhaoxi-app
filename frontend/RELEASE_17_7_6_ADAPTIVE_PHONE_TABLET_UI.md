# ZhaoXi 17.7.6 — Adaptive Phone / Tablet UI

One codebase with automatic viewport-based layouts:
- Phone: < 768px — exact approved mobile dashboard, no fixed sidebar.
- Tablet: 768–1199px — compact Glass sidebar and responsive two-column dashboard.
- Desktop: >= 1200px — full admin layout.

Layout updates automatically on resize and orientation changes.
Business logic, API routes, authentication and Admin Test QR remain unchanged.
