# ZhaoXi Platform 18.1 — Unified Mobile Navigation & Role Experience

One shared navigation architecture for Customer, Partner and Admin.

- Same Aurora/Glass top-level navigation language and geometry.
- Phone: role-aware 5-item fixed bottom navigation.
- Extended role functions: shared Glass menu sheet.
- Single selected locale only; no bilingual navigation labels.
- Tablet: sheet/dialog presentation scales automatically.
- Customer, Partner and Admin each see only their own navigation destinations.
- Existing business logic, authorization, QR login and feature modules remain unchanged.
