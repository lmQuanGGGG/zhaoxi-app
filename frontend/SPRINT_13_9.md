# Sprint 13.9 — Mobile UI, Single-language Flow & Modern Notifications

- All three apps use a mobile-width application frame.
- Shared language/theme/logout controls live inside the application frame.
- Customer alerts, order timeline and notification center use one selected locale only.
- Notification center removes the unread-count heading and uses modern rounded controls.
- Food navigation points to the current marketplace route.
- Customer home removes the redundant scan control and redesigns the location control.
