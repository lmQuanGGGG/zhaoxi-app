# ZhaoXi 17.7.4 — Unified Visual Architecture Baseline

This release establishes the permanent ZhaoXi visual baseline.

Shared across Customer, Partner and Admin:
- Aurora / Soft Pastel background: lavender + ice blue + blush.
- White/glass panels with consistent blur, radius and soft shadow.
- Shared typography stack.
- Shared ZhaoXi top bar architecture.
- Top bar actions: language, light/dark theme, notifications, sign out.
- Shared language-selection shell.
- Shared pre-app login shell.
- Single-language rendering after locale selection; no bilingual login copy.
- Existing authentication, Admin Test QR and business modules remain wired.

This is a visual-system release. Business rules and service APIs are preserved.
