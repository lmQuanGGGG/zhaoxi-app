# ZhaoXi 17.5 — Unified Operations Command Center Platform

Adds a primary Admin Command Center with:
- unified backlog across Support, Customer Ops, Housing and Travel
- SLA forecast for 2h / 24h / 72h
- overdue and unassigned workload
- agent capacity and load planning
- operational bottleneck cards
- unified work queue filters
- module workload distribution

The existing Analytics, Operations, Customer Ops, Support, Housing and Travel screens remain available for drill-down.
