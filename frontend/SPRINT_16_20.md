# Sprint 16.20 — Personalized Home & Recommendation Engine

Cumulative release on Sprint 16.19.

- Customer Home uses an authenticated personalized recommendation feed.
- Ranking signals: Favorites, recent Browsing History, Orders, marketplace popularity, new partners, and service-module affinity.
- Recommendations retain the 60-second smooth horizontal carousel contract from the Customer UI baseline.
- Each recommendation can explain its reason in the currently selected language.
- Anonymous/new Customers still receive the general marketplace feed.
- The recommendation engine keeps category diversity instead of filling the feed with one service type.
- Single-language remains mandatory.
